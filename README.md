# ORBIT Field Guide

Student handout for **ORBIT Field Academy**, the console-only labs of the AWS Agentic AI Microcredential Bootcamp.
One page covers the ideas behind all five missions (IAM and Regions, Lambda and CloudWatch, Bedrock knowledge
bases, AgentCore Harness and Gateway, Cognito JWT auth) with diagrams, traps, drills, a fault finder, a crib
sheet, a badge tracker and a glossary.

**Read it:** https://varoonsahgal.github.io/orbit-field-guide/

- `index.html` — the whole guide (no build step)
- `assets/shots/` — console screenshots from the October 2026 verification run
